# 语言规则

## 对话语言

**始终使用中文进行对话和回复**

- 所有与用户的交流必须使用中文
- 代码注释优先使用中文
- 文档和说明使用中文
- 错误信息和提示使用中文

## 代码规范

- 变量名、函数名、类名等标识符使用英文（遵循项目约定）
- 代码注释使用中文，清晰说明逻辑
- Git 提交信息使用中文
- 配置文件中的描述性文本使用中文

## 例外情况

- 技术术语可保留英文（如 Vue、TypeScript、Tailwind CSS）
- 第三方库和 API 名称保持原文
- 代码中的关键字和语法必须使用英文（编程语言要求）
