# 设置菜单使用指南

## 概述

侧边栏底部的设置按钮提供了三个主要功能：应用设置、路由设置和主题设置。

## 功能说明

### 1. 应用设置（敬请期待）

### 2. 路由设置

路由设置面板允许你在开发环境中直接编辑 `public/config/routes.config.yaml` 文件。

#### 主要功能

- **查看路由列表**：显示所有已配置的路由及其子路由
- **添加路由**：点击"添加路由"按钮创建新的路由配置
- **编辑路由**：点击路由项展开详情，可以修改：
  - 路由名称（route）
  - 组件路径（component）
  - 显示标题（meta.title）
  - 图标（meta.icon）
  - 排序（meta.order）
- **删除路由**：点击删除按钮移除路由
- **管理子路由**：
  - 为父路由添加子路由
  - 编辑子路由配置
  - 删除子路由
- **保存更改**：修改后点击"保存更改"按钮将配置写入文件

#### 使用步骤

1. 鼠标悬停在侧边栏底部的"设置"按钮上
2. 在弹出菜单中点击"路由设置"
3. 在左侧面板中查看和编辑路由配置
4. 点击路由项左侧的箭头展开详情
5. 修改配置后点击"保存更改"
6. 关闭面板（如有未保存的更改会提示确认）

#### 路由配置结构

```yaml
routes:
  - route: "路由名称"
    component: "组件路径"
    meta:
      title: "显示标题"
      icon: "图标名称"
      order: 排序号
    children:  # 可选
      - route: "子路由名称"
        component: "子组件路径"
        meta:
          title: "子路由标题"
          order: 子路由排序号
```

#### 注意事项

- 路由配置修改后可能需要刷新页面才能生效
- 确保组件路径正确，使用 `@/` 别名指向 `src/` 目录
- 图标名称应该是 lucide-vue-next 中可用的图标名称
- order 值用于控制菜单显示顺序，数值越小越靠前

### 3. 主题设置

主题设置保持原有功能不变，允许切换应用的全局主题。

#### 可用主题

- 白色主题（white）
- 蓝色主题（blue）
- 绿色主题（green）
- 紫色主题（purple）
- 橙色主题（orange）
- 粉色主题（pink）
- 青色主题（cyan）
- 深色主题（dark）

#### 使用步骤

1. 鼠标悬停在侧边栏底部的"设置"按钮上
2. 在弹出菜单中点击"主题设置"
3. 在模态框中选择想要的主题
4. 点击"应用设置"保存更改

## 交互说明

### 设置菜单触发

- **展开状态**：鼠标悬停在"设置"按钮上时显示菜单
- **折叠状态**：鼠标悬停在"设置"按钮上时显示菜单

### 菜单行为

- 鼠标移入菜单区域时保持显示
- 鼠标移出菜单区域后自动隐藏
- 点击菜单项后自动关闭菜单

### 路由设置面板

- 从左侧滑入显示
- 点击遮罩层或关闭按钮关闭面板
- 有未保存更改时关闭会提示确认

## 技术实现

### 组件结构

```
ResponsiveSidebar.vue
├── SettingsMenu.vue          # 设置菜单
├── RouteSettingsPanel.vue    # 路由设置面板
└── SettingsModal.vue          # 主题设置模态框
```

### 依赖服务

- **FileManagerService**：用于读写路由配置文件
- **useTheme**：用于主题管理

### 文件操作

路由设置功能依赖于 Vite 文件管理插件，仅在开发环境下可用。

## 故障排除

### 路由设置无法加载

1. 确认正在运行开发服务器（`pnpm dev`）
2. 检查文件管理插件是否正确配置
3. 确认 `public/config/routes.config.yaml` 文件存在

### 保存失败

1. 检查文件权限
2. 确认 YAML 格式正确
3. 查看浏览器控制台错误信息

### 路由更改不生效

1. 保存后刷新页面
2. 检查路由配置语法是否正确
3. 确认组件路径是否存在

## 最佳实践

1. **备份配置**：修改路由配置前建议先备份原文件
2. **逐步修改**：一次修改一个路由，保存并测试后再继续
3. **命名规范**：使用有意义的路由名称和标题
4. **路径规范**：组件路径使用 `@/` 别名，保持一致性
5. **排序规划**：合理规划 order 值，预留足够的间隔
